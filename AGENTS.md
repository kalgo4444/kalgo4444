## Overview

Personal landing page for Abdulaziz Abdugafurov: a single static-style page with a name heading and social links (LinkedIn, Twitter, GitHub, Telegram, Email). Next.js App Router, React 19, Tailwind CSS v4, TypeScript (strict), Bun as package manager.

## Commands

```bash
bun install
bun run dev      # next dev
bun run build    # next build
bun run start    # next start
```

There is no test runner and no lint script configured. Type-check with `bunx tsc --noEmit`.

## Architecture

- **Versions are bleeding edge** (Next 16.x, React 19.3, Tailwind 4.3). Your training data may not match them; check the bundled docs in `node_modules/next/dist/docs/` (`01-app` is the App Router) before using Next APIs.
- **`next.config.ts`** enables `cacheComponents`, `partialPrefetching`, and the React Compiler (`reactCompiler: true`, via `babel-plugin-react-compiler`). Don't add manual `useMemo`/`useCallback` memoization. Under `cacheComponents`, dynamic data access in routes must be handled per the Next 16 caching docs.
- **Tailwind** is wired through Turbopack, not PostCSS: `turbopack.rules` in `next.config.ts` runs `@tailwindcss/turbopack` on `*.css`. There is no `postcss.config` or `tailwind.config`. `src/app/globals.css` is just `@import "tailwindcss";`.
- **Routing:** the page lives in the `(home)` route group (`src/app/(home)/page.tsx`) and serves `/`. `src/app/layout.tsx` is the root layout (JetBrains Mono via `next/font/google`, applied on `<html>`). It uses the global `LayoutProps<"/">` type generated by Next's typegen, so run `dev`/`build` once if that type is missing.
- Path alias `@/*` maps to `./src/*`.
- The social links are a data array (`links`) in `src/app/(home)/page.tsx`. Icons come from `lucide-react`.

## Repo conventions

- `docs/index.md` holds the contact info and `README.md` holds the profile bio. Keep them consistent with the links in the page.
- Pushing to the remote: use the SSH remote URL (user's global instruction).
- `opencode.jsonc` and `.claude/settings.json` define agent permissions. Both deny `rm -rf` and reading `.env`; `opencode.jsonc` also denies `git push`.
